## 实际修复

- 补齐公开 50 工具合同中原来遗漏的 9 组真实行为注解；设备/项目查询标记只读，命令、写入、切换状态保持真实语义。公网部署前缺 9 项，部署后缺 0 项。
- 优化明确目录的直接路由与 PowerShell 使用引导，减少无必要的列目录/查询当前项目/切换及嵌套引号失败。单条项目内读写删除测试通过；这不是消费者 Gemini 弹窗次数的对照实验。
- 标准 Basic OAuth 请求无需重复提供表单 client_id；重复/冲突参数、注册方式、PKCE、资源约束继续检查。原七项失败已在此前接入修复中通过，全版本回归覆盖保留。
- 原生 Mac 支持 arm64 和 Intel：Finder 私有运行时、配置目录兼容、初始化幂等、Info.plist 防御检查、包元数据和安装资产匹配。
- Intel cryptography 改为锁定版本的静态 OpenSSL 构建，修复冻结包 `_SSL_get0_group_name` 缺失；构建前用 otool 和内存加密往返核验，禁止带动态同名库冲突的包进入冻结阶段。
- Darwin cloudflared 归档以随锁版本维护的官方摘要验证，消除每次构建依赖未认证 GitHub Release API 的限流问题，不降低实际二进制校验。

## 能力边界与未覆盖环境

Google 消费者官方仍要求写操作人工确认；工具注解是描述行为的提示，不能覆盖客户端策略。本版没有将命令伪装成只读，也不宣称十次弹窗已实测降为某个固定次数。无需因本次更新重新生成访问码或重建 GPT 插件。
Mac 包为 ad-hoc 签名，未进行 Developer ID 签名或 Apple 公证；当前 Mac 更新方式是下载替换，不是原位自动热更新。CI 原生验证不等于已在用户 Mac 上完成首次安装和隐私权限验收。
GRW 仍运行其专用中转版本；本轮只读对照确认其 relay_control/SSH 服务控制尚未并入通用发行包，因此没有用 WJP 安装器覆盖 GRW 或更改其隧道。该独立部署任务继续保留。
